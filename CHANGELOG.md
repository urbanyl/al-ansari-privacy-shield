# Changelog

## 1.0.0 — 2026-10-29

First public release of **Al-Ansari Privacy Shield**.

### Added

- 17 reversible privacy protections across telemetry, advertising, search, activity and location.
- Dashboard with privacy score, category progress and pending-change counter.
- Three profiles: Balanced, Strict and Maximum.
- Apply-on-demand workflow: nothing is written until **Apply changes**.
- Automatic backup of registry values and service start types, change journal and report export.
- Full restore of every original value.
- Classic Win32-style English interface, loading screen, tray mode and administrator elevation.
